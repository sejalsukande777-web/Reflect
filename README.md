# Reflect – Daily Reflection & Self-Growth Web App

Reflect is a full-stack web application that helps users record their daily thoughts, track their mood, maintain reflection streaks, and visualize personal growth through analytics.

## Features

- User Registration & Login
- Secure JWT Authentication
- Daily Journal Entries
- Mood Tracking
- Reflection Streaks
- Analytics Dashboard
- Responsive User Interface

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript
- Chart.js
- Google Fonts

### Backend
- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- JWT
- bcrypt
- dotenv
- CORS

## Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to backend

```bash
cd backend
npm install
```

Create a `.env` file.

Start backend

```bash
npm start
```

Run the frontend using Live Server.

Backend:
```
http://localhost:5000
```

Frontend:
```
http://localhost:5500
```
